# 智慧树自动听课

本地小工具：在**你自己的账号、你自己已购课程**上，把「看视频 + 弹题作答」这件事自动化。

- 后台无头播放（Chrome 由程序拉起并移出屏幕可视区，可最小化）
- 弹题出现时读取题目 → 调 DeepSeek 选出答案 → 用真实鼠标点选提交 → 关弹窗继续播
- 一节看完自动跳下一节；也可以在前端课程目录里手动点任意一节
- 断点续播：随时「退出」不破坏程序，下次从平台记录的进度继续
- 全程只在本机跑：Vue 仪表盘 + 本地 Node 服务 + 独立 Playwright worker，不上传任何数据

---

## 一、三步用起来

1. 双击 **start.bat**（首次会装依赖、构建界面，之后秒开）。
2. 浏览器自动打开仪表盘 → 点右上角 **「开始听课」**。
3. 会弹出一个 Chrome 窗口，在里面登录智慧树：
   - **扫码登录**（微信 / QQ）——任意一种；
   - 如果这台电脑之前登录过，通常**自动登录**，不用扫码；
   - 登录后程序会自己回到上次的课程继续播，不需要你点选课程。

> 这个 Chrome 窗口**不要关**，最小化即可。仪表盘里点「退出」会保存断点并关掉浏览器。
>
> **不小心把仪表盘网页关了？** 双击同目录的 **打开界面.bat** 就能重新打开（后台还在正常跑）；
> 再双击一次 start.bat 也可以——它会发现服务已在跑，直接开界面。

想听别的节：在仪表盘左下的 **课程目录** 里点那一节即可（不用碰浏览器窗口）。
想听别的课：点顶部中间的课程胶囊（写着「我的课程 · 课程名」）→ 弹窗里点「刷新」读列表 → 点哪门就切到哪门（会自动跳到那门课没听完的小节）。

## 二、界面

整个仪表盘**固定一屏**（按窗口高度布局，不出现整页上下滚动），只有列表内部在自己滚动。

| 位置 | 区域 | 说明 |
| --- | --- | --- |
| 顶栏 | 我的课程 | 顶部中间的课程胶囊：显示当前课程，点开是「我的课程」弹窗（账号下所有课程 / 老师 / 学校 / 平台进度），点哪门切哪门，Esc 或 ✕ 关闭 |
| 顶栏 | 操作按钮 | **开始听课 / 暂停 / 继续 / 重启 / 退出**；退出后按钮变「重新开始」，回到上次的课和进度 |
| 左主列 | 当前课程大卡 | 课程名、学校、章节、任务点序号、状态徽章、本段播放进度（当前位置 / 总时长、倍速、已看）、本节弹题点（已答 / 下一题 / 未到） |
| 左主列 | 学习进度总览 | 大卡底部一条：本节视频 / 本章节 / 本课程 / 全部课程，四层百分比（读不到就显示 —，不编数字） |
| 左主列 | 课程目录 | 按章节分组，自适应列数（宽屏 4~6 列、窄屏 2~3 列）铺满，当前节高亮；每节显示「已完成 / xx% / 未开始」，点一下就切过去 |
| 右栏 | 下一题 | 距下一道弹题还有多久、题号；**每秒跟着视频走**，切到新视频立刻按新视频的弹题点重算（读不到时显示「读取中」，不会假装「本段已结束」） |
| 右栏 | 自动答题 | 自动作答开关、**看完自动跳下一节**开关、答题模型自检、策略、今日已答（含答对几题） |
| 右栏 | 章节测试 | 每章视频看完自动做「平时测试」并自动交卷；已交过的章显示「已交 · 得分」；平台已交的标「已交（之前）」；每行可「现在做」；卡片头有「自动做章节测试」开关（默认开） |
| 底部 | 运行日志 / 答题记录 | 常驻底栏两个页签：运行日志（全部动作与中文人话报错）+ 答题记录（题面、选了什么、对错），最新在最下面 |
| 浮层 | 浮动提示条 | 人机验证 / 各类提醒，飘在左下角、不挤压页面，右上角 × 可手动关掉（有新提醒时自动再出现） |

## 三、答题：接 DeepSeek（可选，不配也能看）

题库题的答案由大模型来选，配置在 **data/config.json**：

```json
{
  "llm": {
    "provider": "deepseek",
    "apiKey": "sk-你的key",
    "baseUrl": "https://api.deepseek.com",
    "model": "deepseek-flash",
    "maxTokens": 1024,
    "timeoutMs": 30000
  }
}
```

- 填好 key 后，界面「答题模型」一行点 **测试模型**，会用一道样题试一次并显示耗时与结果（正确/错误会写明）。
- 答题时：读题面 → 只把题干和选项发给模型 → 模型回一个选项字母 → 用**真实鼠标**点这个选项 → 平台自动提交 → 读回「正确/错误 + 正确答案」记进最近答题。
- **没配 key 时不会乱猜**：弹题出现会暂停，提示你手动作答（避免把随机答案记进成绩）。
- 答错不影响继续播放，平台只记录答过没答；但成绩记在账号上，介意就别开自动答题。
- key 只存在本机 data/config.json，服务只监听 127.0.0.1 且带随机 token；data/ 目录别提交到任何仓库。

## 四、自动跳节怎么判

平台课程树里每节有三种状态，程序按 DOM 标记识别：

- 已看完：有完成图标（只剩时长、没有百分比）→ **跳过，不再重播**；
- 看了一半：有百分比（如 55%）→ 优先接着看；
- 未开始：没有百分比也没有完成图标。

一节播完时（播放器触发 ended，或只是停在 100% 不发 ended——两种都算），即使平台还没把课程树刷新成「已完成」，也按播完处理，自动点下一节。
没有可切的下一节时停下并提示「这门课能自动听的节都听完了」。

关掉「看完自动跳下一节」后，一节播完会停下等你，你在课程目录里手动点下一节。

## 五、章节测试（平时测试）自动答题

每一章的视频**全部看完**后，程序会自动打开那一章的「平时测试」，按顺序答完 → 点「提交作业」→ 在确认框点「确定」。界面右侧「章节测试」卡片列出全部章节和状态。

- 只在整章视频都看完后才做，没看完不会提前交卷；
- 一次只做一份试卷，做题期间视频和弹题照常处理（互不阻塞）；
- **平台上已经交过的测试自动跳过**：课程树上打了对勾（`b.finish`）的章节直接显示「已交（之前）」，不会点开重答；
  万一真的点开了已交的卷子（平台打开的是「查看」页，没有「提交作业」按钮），也会认出来并立刻退出，不会把已交的卷子改成未交；
- 每题：模型答完会回读勾选状态（智慧树把选中态放在 class `onChecked` 上，不是原生 checked）；模型回复里抠不出字母时会**再问一次**（只许回字母），还不行才用兜底策略；
- 答完按答题卡核对，有漏答的自动翻回去补；交卷后读回得分，显示「已交 · 得分 14/16」；
- 想手动补某一章：在卡片里点那一行的「现在做」；把「自动做章节测试」关掉就只在手动点击时做。

---

平台有反脚本/反调试机制，所以本工具的原则是**极小化足迹**：

1. **页面内零注入** —— 不往网页里塞脚本、不装 MutationObserver、不改 DOM；状态用 Playwright 只读 evaluate 采样。
2. **只用真实输入** —— 点选项、关弹窗、点课程树全部走 Playwright 的鼠标事件（isTrusted=true）。
   曾经用 `element.click()` 合成事件，平台立刻弹「检测到异常脚本」并强制跳回学堂，已彻底改掉。
3. **平时待机** —— 弹题时刻由平台接口提前下发（`popupAnswer/loadVideoPointerInfo`），不需要持续盯 DOM。
4. **低频采样** —— 约每秒一次只读取播放时间/弹窗可见性，不刷接口。
5. **后台不被降频** —— 关掉后台节流开关、窗口移出可视区（不是 display:none，视频照常解码）。
6. **万一触发提示** —— 检测到「异常脚本/关闭插件」提示会自动重新进入视频页续播，并记日志。
7. **撞上人机验证就交给人** —— 智慧树风控偶尔会弹「请完成安全验证」（腾讯点选验证码）。检测到就把视频停下、
   在界面亮紫色提示条「等待人机验证」，你在浏览器窗口点掉，它自动接着放。**故意不让 AI 去硬解**：
   验证码是给真人看的，模型看图给坐标并不稳（实测坐标要靠猜），点错会升级风控，代价远大于点一下。
   顺带一提：验证码多半是被「反复重启 / 连续点课程树 / 短时间来回切课」招来的，所以重试都是克制的。

## 七、出错时会怎样

- 任何异常都**不会把代码报错抛给界面**：统一 `{code, message, hint}` 中文人话。
- worker 崩了服务会自动拉起（1 小时内最多 4 次），界面显示「正在自动恢复」；超过则停下提示点「重启」。
- 弹窗结构改版导致读不到选项 → 自动停下等你手动答，绝不乱点。
- 出现人机验证 → 视频暂停、界面显示「等待人机验证」，你点掉后自动继续（不需要重启程序）。
- 视频卡在 100% 不动 → 程序会自己认出「播完了」，自动点下一节；真卡在中间不动，会先自己重试播放，超过约 5 分钟才停下提示你点一下播放键。
- 界面网页关掉/刷新都不影响后台：双击 **打开界面.bat** 重新打开即可（它读 data/server.url 里的带 token 地址）。
- 日志与断点：data/runtime.log、data/state.json、data/debug/（调试模式下弹窗 HTML/截图，只用于排错）。

**想重置一切**：退出程序，删掉整个 data/ 目录，重新双击 start.bat。
（data/profile/ 是 Chrome 用户目录，登录态存在这里；data/config.json 是你的 API key。）

## 九、已知限制

- 只支持 Windows（start.bat）；其它系统可手动 `node server/index.mjs`。
- 自动做测试只覆盖每章的「平时测试」；期末、补考、非章节测试的作业不自动做。
- 不同课程弹题节奏不同；平台改版（DOM 或接口）可能让某些环节退化，退化时程序会停下等手动，而不是乱操作。
- 答题正确率取决于模型与课程内容，不能保证全对；成绩风险自负。
- 同时只跑一个实例（端口 8731 单占用）；重复双击 start.bat 会直接打开已运行的界面。
- 服务跑在一个标题为「智慧树自动听课 - 服务运行中（关掉这个窗口=停止服务）」的窗口里，**关掉它服务就停**（进度已保存，重开 start.bat 会接着来）。
