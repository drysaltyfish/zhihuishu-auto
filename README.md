# 智慧树自动听课

**Windows 桌面程序（免安装）**：下载解压后双击就能用，不需要另外装 Node、npm，也不用自己装浏览器。它在**你自己的账号、你自己已购的课程**上，把「看视频 + 弹题作答」自动化。

- 自动播课：程序自己拉起浏览器窗口，并把它移出屏幕、从任务栏隐藏；你只需要面对一个界面
- 弹题出现 → 读题面 → 调大模型选答案 → 用真实鼠标点选提交 → 关弹窗继续播
- 一节看完自动跳下一节；整章看完自动做「平时测试」并交卷
- 断点续播：随时退出都不破坏进度，下次从平台记录的进度接着来
- 全程只在本机跑：数据都在程序旁边的 `data/` 里，不上传到任何服务器

## 一、下载与运行（免安装）

只有免安装版，没有安装程序，不需要管理员权限。

1. 拿到程序包，二选一（版本号以文件名里的为准）：
   - `release\ZhihuishuAuto-0.1.0-portable.zip` —— **目录版，推荐**：解压到任意**可写**目录（别放 `C:\Program Files`），双击里面的 `ZhihuishuAuto.exe`。
   - `release\ZhihuishuAuto-0.1.0-portable.exe` —— **单文件版**：放到任意**可写**目录，双击即可，不用解压。
2. 第一次启动会自动在程序旁边创建 `data/`——登录态、配置、日志都在里面。
3. 想放到桌面/开始菜单，给 exe 建个快捷方式即可；**目录版别把 exe 单独挪走**（要连同同目录的 `resources/`、`locales/` 等一起）。
4. 不用了直接删掉整个程序目录就是卸载；想连数据一起清空，把 `data/` 也删掉。

> 程序没有做代码签名，Windows 可能提示「未知发布者」。点「更多信息」→「仍要运行」即可；想自己签掉这个提示，见 [docs/代码签名指南.md](docs/代码签名指南.md)。

> 两种包的区别：单文件版每次启动会先把自身解压到系统临时目录（启动稍慢、退出自动清理），数据目录**不会**跟着进临时目录，仍在你放 exe 的那个目录旁边；目录版启动快。万一程序发现自己跑在临时目录里（例如直接在压缩软件的预览窗口里双击），会把数据放到 `%APPDATA%\ZhihuishuAuto\data`，并在日志里提醒。

## 二、三步用起来

1. 打开桌面上的「智慧树自动听课」。
2. 点右上角 **「开始听课」**。
3. 界面中央会弹出扫码登录：**用微信扫二维码，并在手机上确认**。
   登录成功后浮层自动关闭，程序回到上次的课程和进度继续播，不用再点一次开始。
   二维码约 2 分钟有效、过期自动换一张；实在扫不了可以点「在浏览器窗口中登录」。

登录一次后登录态存在 `data/profile/`，以后通常是自动登录。

几个日常操作：

- **关掉窗口不会退出**：点 ✕ 只是把界面隐藏到托盘，后台照常听课。
  再打开就点托盘图标，或托盘菜单「打开界面」。
- **真正退出**：右键托盘图标 →「退出」。这样服务、浏览器、后台进程会一起停掉，进度已保存。
- **顶栏的「退出」按钮只停止听课**，程序仍在托盘里运行；要关程序用托盘菜单。
- **开机自启**：托盘菜单里的「开机自动启动」，或到「设置 → 桌面能力 → 开机自启」打开。开启后开机自动在后台跑，不弹窗口。
- **看/藏后台浏览器**：后台的 Chrome 窗口默认被移到屏幕外，你是看不见的。点顶栏 **「显示浏览器」** 把它叫到前台——手动扫码登录、手动点开某个不跳的节点、过滑块验证时用；弄完再点 **「隐藏浏览器」** 藏回屏幕外。

## 三、界面

顶部导航四个页面：**总览 / 选课 / 设置 / 日志**。顶栏还有课程胶囊（显示当前课程，点开可以切课）、连接状态和听课操作按钮
（开始听课 / 暂停 / 继续 / 重启 / 退出），以及 **「显示浏览器」/「隐藏浏览器」**（听课进行中才出现，见下）。

| 页面 | 里面有什么 |
| --- | --- |
| 总览 | 固定一屏的仪表盘：左边是**当前课程大卡**（课程名、学校、章节、任务点、状态、本段播放进度、本节弹题点）和**课程目录**；右边是**下一题**（距下一道弹题还有多久）、**自动答题**（开关、模型自检、今日已答）、**章节测试**（每章状态/得分/「现在做」）；底部常驻**运行日志 / 答题记录**双页签。整页不滚动，只有卡片里的列表自己滚。 |
| 选课 | 账号下全部课程列表（课程名 / 老师 / 学校 / 平台进度），点哪门就切到哪门，不打断当前进度；下面是这门课的完整课程目录，点任意一节直接切过去。这一页内容多，可以整页滚动。 |
| 设置 | **模型设置**：API Key（可显示/隐藏）、Base URL、模型名、请求超时，可「保存设置」或「保存并重启后台」，还能「测试模型」「清除 Key」。**自动化开关**：弹题自动作答、看完自动跳下一节、自动做章节测试，改完立刻生效。**桌面能力**：打开数据目录、导出日志、开机自启、检查更新、重启程序。底部是版本号。 |
| 日志 | 全屏日志查看器：级别筛选（全部 / 信息 / 警告 / 错误）、关键字搜索、自动滚动开关、清屏（只清界面，不动文件）、导出日志。显示最近 300 条，底部有各级别条数。 |

> 「下一题」每秒跟着视频走，切到新视频立刻按新视频的弹题点重算；读不到时显示「读取中」，不会假装本节已经播完。

## 四、答题：接 DeepSeek（可选，不配也能看）

弹题的答案由大模型来选。在 **设置 → 模型设置** 里填：

- **API Key**：你的 DeepSeek（或任意 OpenAI 兼容接口）Key，`sk-` 开头
- **Base URL**：例如 `https://api.deepseek.com/v1`
- **模型名**：例如 `deepseek-chat`
- **请求超时**：毫秒，默认 20000（3～180 秒之间）

填好点「保存设置」，再点「测试模型」会用一道样题试一次并显示结果。改了 Key / 地址后建议点「保存并重启后台」，让后台进程用新配置。

- 答题时：读题面 → **只把题干和选项**发给模型 → 模型回一个选项字母 → 用**真实鼠标**点这个选项 → 平台自动提交 → 读回「正确/错误 + 正确答案」记进答题记录。
- **弹题没配 Key 时不会乱猜**：弹题出现会暂停，等你手动作答（避免把随机答案记进成绩）。
- **章节测试建议先配 Key**：没配 Key 时「自动做章节测试」会用兜底策略硬选（单选选最长、判断选「对」、多选选第一个），正确率没有保证；不想这样就把「自动做章节测试」关掉。
- 答错不影响继续播放，平台只记录答过没答；但成绩记在账号上，介意就别开自动答题。
- Key 只存在本机 `data/config.json`，不会上传；服务只监听 `127.0.0.1` 且带随机 token。

## 五、自动跳节怎么判

平台课程树里每节有三种状态，程序按页面标记识别：

- 已看完：有完成图标（只剩时长、没有百分比）→ **跳过，不再重播**；
- 看了一半：有百分比（如 55%）→ 优先接着看；
- 未开始：没有百分比也没有完成图标。

一节播完时（播放器触发 ended，或只是停在 100% 不发 ended——两种都算），即使平台还没把课程树刷新成「已完成」，也按播完处理，自动点下一节。
没有可切的下一节时停下并提示「这门课能自动听的节都听完了」。

关掉「看完自动跳下一节」后，一节播完会停下等你，你在课程目录里手动点下一节。

## 六、章节测试（平时测试）自动答题

每一章的视频**全部看完**后，程序会自动打开那一章的「平时测试」，按顺序答完 → 点「提交作业」→ 在确认框点「确定」。「总览」右侧的「章节测试」卡片列出全部章节和状态。

- 只在整章视频都看完后才做，没看完不会提前交卷；
- 一次只做一份试卷，做题期间视频和弹题照常处理（互不阻塞）；
- **平台上已经交过的测试自动跳过**：课程树上打了对勾的章节直接显示「已交（之前）」，不会点开重答；
  万一真的点开了已交的卷子（平台打开的是「查看」页，没有「提交作业」按钮），也会认出来并立刻退出，不会把已交的卷子改成未交；
- 每题：模型答完会回读勾选状态（智慧树把选中态放在 class `onChecked` 上，不是原生 checked）；模型回复里抠不出字母时会**再问一次**（只许回字母），还不行才用兜底策略；
- 答完按答题卡核对，有漏答的自动翻回去补；交卷后读回得分，显示「已交 · 得分 14/16」；
- 想手动补某一章：在卡片里点那一行的「现在做」；把「自动做章节测试」关掉就只在手动点击时做（这个开关在设置页和章节测试卡片上都有）。

## 七、反检测铁律

平台有反脚本/反调试机制，所以本工具的原则是**极小化足迹**：

1. **页面内零注入** —— 不往网页里塞脚本、不装 MutationObserver、不改 DOM；状态用 Playwright 只读采样。
2. **只用真实输入** —— 点选项、关弹窗、点课程树全部走 Playwright 的鼠标事件（isTrusted=true）。
   曾经用 `element.click()` 合成事件，平台立刻弹「检测到异常脚本」并强制跳回学堂，已彻底改掉。
3. **平时待机** —— 弹题时刻由平台接口提前下发（`popupAnswer/loadVideoPointerInfo`），不需要持续盯 DOM。
4. **低频采样** —— 约每秒一次只读取播放时间/弹窗可见性，不刷接口。
5. **后台不被降频** —— 关掉后台节流开关；浏览器窗口用 `WS_EX_TOOLWINDOW` 去掉任务栏按钮并移到屏幕外（不是最小化、不是 display:none），页面里的 `visibilityState` 仍是 visible，视频照常解码。
6. **万一触发提示** —— 检测到「异常脚本/关闭插件」提示会自动重新进入视频页续播，并记日志。
7. **撞上人机验证就交给人** —— 智慧树风控偶尔会弹「请完成安全验证」（腾讯点选验证码）。检测到就把视频停下、
   在界面亮紫色提示条「等待人机验证」，你在浏览器窗口点掉，它自动接着放。**故意不让 AI 去硬解**：
   验证码是给真人看的，模型看图给坐标并不稳（实测坐标要靠猜），点错会升级风控，代价远大于点一下。
   顺带一提：验证码多半是被「反复重启 / 连续点课程树 / 短时间来回切课」招来的，所以重试都是克制的。

## 八、数据和隐私

所有数据都在**程序所在目录的 `data/`**（单文件版就是放 exe 的那个目录；开发版在仓库的 `data/`）：

| 路径 | 内容 |
| --- | --- |
| `data/profile/` | 浏览器用户目录，智慧树登录态和 Cookie 在这里 |
| `data/config.json` | 模型配置，**含 apiKey** |
| `data/state.json` | 断点：上次看到哪个视频（重启后从这里接着播） |
| `data/quizzes.json` | 章节测试断点：每章做过没有、得多少分 |
| `data/logs/main.log` | 运行日志（单文件最多 5MB，自动轮转） |
| `data/electron/` | Electron 自己的 Chromium 缓存（程序把它重定向到这里，尽量不写程序目录外） |
| `data/exports/` | 导出的日志 zip |
| `data/login-qr.png` | 当前的登录二维码（程序从浏览器里截出来给界面显示） |
| `data/window.json` | 窗口位置和大小 |
| `data/debug/` | 调试模式下的页面结构/截图，只用于排错，平时不生成 |

- **服务只监听 `127.0.0.1`**，每次启动带一个随机 token；界面地址形如 `http://127.0.0.1:<随机端口>/?t=<token>`，其它机器访问不到。
- **不联网上传**：程序不向任何自建服务器发数据。只有你配置的模型接口会收到题干和选项；课程、账号信息留在本机。
- **删掉程序目录即卸载**：程序不往系统目录写东西，`data/` 跟着程序目录走。
- **想重置一切**：先托盘「退出」，再删掉整个 `data/` 目录，重新打开程序。
- `data/` 别提交到任何仓库、也别随手发给别人（里面有登录态和 apiKey）。

## 九、更新

**免安装版没有自动更新**：electron-builder 的 portable 目标不生成 `latest.yml` / 差分元数据，所以设置页「检查更新」会直接显示「免安装版不支持自动更新」。

升级方式就是手动换程序：

1. 下载新版（`portable.exe` 或 `portable.zip`）。
2. 先托盘「退出」关掉程序。
3. 把新版解压/放到新目录（新目录更稳，能留着旧版回滚），**别覆盖 `data/`**——登录态和进度都在里面。
4. 双击新版即可，它会接着用旁边的 `data/`。

> 想搬到另一台机器：连同 `data/` 一起复制过去，登录态和进度就跟着走（`data/` 里有登录态和 apiKey，别发给别人）。

开发模式（`npm run desktop:dev`）不检查更新。

## 十、出问题时

- 任何异常都**不会把代码报错抛给界面**：统一 `{code, message, hint}` 中文人话。
- worker 崩溃会自动拉起（1 小时内最多 4 次），界面显示「正在自动恢复」；超过则停下提示点「重启」。
- 弹窗结构改版导致读不到选项 → 自动停下等你手动答，绝不乱点。
- 出现人机验证 → 视频暂停、界面显示「等待人机验证」，你点掉后自动继续（不需要重启程序）。
- 视频卡在 100% 不动 → 程序会自己认出「播完了」，自动点下一节；真卡在中间不动，会先自己重试播放，超过约 5 分钟才停下提示你点一下播放键。
- **自动切下一节点了没反应**（课程树点了但视频不换）→ 连续 2 轮失败后不再硬试：自动暂停、把浏览器窗口弹到前台，界面顶部常驻提示「请手动点开要听的节，弄好后点『继续』」。手动点好那节课，再点「继续」，程序就从当前节接着听。
- **偶尔弹出「学前必读」「学习须知」「温馨提示」这类提示弹窗** → 程序会自己点掉（优先「我知道了/关闭」，没有就点「开始学习」，要先勾「我已阅读」会先帮你勾上），关掉之后继续听课；弹题和人机验证**绝不会**被当成提示弹窗。万一哪天没关掉，日志里会有「看到提示弹窗「…」但没点动」，把日志导出给开发者即可。
- **启动失败**会显示一个中文错误页（「本地服务没能启动」），点「重试」再启动一次，或「退出程序」。
- 后台卡住 → 设置 → 桌面能力 → 「重启程序」。
- 界面本身打不开/点了没反应 → 托盘菜单「打开界面」。

**要反馈问题，先导出日志**：设置页或日志页点「导出日志」，会生成
`data/exports/zhihuishu-logs-<时间戳>.zip`，里面是运行日志、系统信息和脱敏后的配置（**apiKey 已打码**，只留前 3 位和后 4 位）。把这个 zip 发给开发者即可，不用自己翻目录。

### 双击没反应 / 启动不起来

按顺序排查，这几类几乎覆盖全部情况：

1. **是不是没等够**：单文件版（-portable.exe）每次启动要先把自身（约 780 MB）解压到系统临时目录，慢的机器要十几秒到半分钟，期间**没有任何窗口**。目录版（zip 解压出来的）是秒开。
2. **是不是放在了不该放的目录**：不要放 C:\Program Files，不要直接在压缩软件的预览窗口里运行，也**不要在项目源码目录里直接双击 release 里的产物**——某些开发工具（包括 AI 编程助手的文件沙箱）会把项目目录里的文件标成「低完整性（Low）」，Electron 从这种目录启动会直接崩溃，而且连日志都不留。把程序复制或解压到 D:\ZhihuishuAuto 这类普通目录再试。
3. **看日志**：程序目录旁边的 data\logs\main.log。
   - 没有 data\ 目录：主进程根本没起来，基本就是第 2 条或杀软拦截；
   - 有 data\ 但界面打不开：把 main.log 最后 20 行发出来，或用「设置 → 导出日志」。
4. **杀软拦截**：国产杀软常把没签名的新 exe 静默拦掉，检查隔离区，或临时关掉实时防护再试一次。
5. **托盘里找找**：关窗口不等于退出，程序可能已经在右下角托盘里跑着，双击托盘图标即可。
6. **还不确定文件有没有问题**：在 PowerShell 里执行 icacls 程序路径，输出里若出现 Low Mandatory Level 就是第 2 条的「低完整性」问题。

想让它显示发布者名、少一点「未知发布者」弹窗：见 [docs/代码签名指南.md](docs/代码签名指南.md)。

## 十一、目录结构

```
desktop/                     Electron 主进程（桌面壳）
  main.mjs                   入口：单实例锁、窗口、托盘、开机自启、IPC、启动/停止本地服务
  tray.mjs                   托盘菜单：打开界面 / 开机自动启动 / 退出
```

## 十二、开发者

需要 Node.js（装当前的 LTS 即可）和 npm。下面命令按 **cmd** 写；PowerShell 里把 `set VAR=值` 换成 `$env:VAR="值"`。

```bat
npm install
npm run browsers:install
npm run web:build
npm test
node scripts/selftest.mjs
npm run desktop:dev
```

- **npm install**：如果 npm 配了国内镜像，建议把缓存指到仓库内，避免 C 盘/权限问题：

  ```bat
  set npm_config_cache=%CD%\.npm-cache
  npm install
  ```

- **npm run browsers:install**：把 Playwright 的 Chromium（只留 chromium + winldd，去掉 headless_shell/ffmpeg）复制到 `browsers/`，供打包内置。
  下载慢的话用国内镜像，见 `scripts/install-browsers.mjs` 顶部注释里的命令。
- **npm run web:build**：重建界面到 `server/public/`。
- **npm test**：跑 `test/` 下的纯函数单元测试（node:test，不用启服务）。
- **node scripts/selftest.mjs**：50 项端到端自检（需要浏览器，慢；不碰真实课程）。
- **npm run desktop:dev**：以开发模式启动桌面程序（用仓库里的 `browsers/`，数据写到仓库 `data/`，不写开机自启）。
- `npm run start:mock`：只开本地服务 + 假引擎，用来联调界面（不连智慧树）。

打包：

```bat
npm run desktop:dir    :: 只生成未打包目录（release\win-unpacked，用来快速验证）
npm run dist           :: 生成免安装包（release\ZhihuishuAuto-<版本>-portable.exe 和 -portable.zip）
```

国内网络建议先设置镜像再打包：

```bat
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
set ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
npm run dist
```

- 打包前会先跑 `npm run web:build`（`desktop:dir` 和 `dist` 都包含）。
- `dist` 一次出两个产物，靠扩展名区分：`-portable.exe` 是单文件免安装版（自解压到临时目录），`-portable.zip` 就是目录版（`win-unpacked` 直接压缩），两者用同一份代码和 `data/` 规则。
- 包体积主要来自内置 Chromium（`browsers/`，约 446 MB）；没执行过 `browsers:install` 时打出来的包缺少内置浏览器，只能依赖系统 Chrome。
- `release/` 里的 `builder-debug.yml`、`*.log` 是构建日志，可以删。

## 十三、已知限制

- 只支持 **Windows x64**（免安装包按此打包）。
- 自动做测试只覆盖每章的「平时测试」；期末、补考、非章节测试的作业不自动做。
- 不同课程弹题节奏不同；平台改版（DOM 或接口）可能让某些环节退化，退化时程序会停下等手动，而不是乱操作。
- 答题正确率取决于模型与课程内容，不能保证全对；成绩风险自负。
- 同时只跑一个实例：再双击快捷方式不会开第二个，只会把已有窗口叫出来。
- 未做代码签名：Windows SmartScreen 可能提示「未知发布者」，需要手动「仍要运行」；部分企业电脑策略会直接拦截。
- 包体比较大：内置 Chromium 约 446 MB，0.1.0 实测单文件 exe 约 243 MB、portable.zip 约 349 MB、解压后约 780 MB；装了系统 Chrome 的机器会优先用系统 Chrome。
- 单文件版每次启动要解压自身到临时目录，启动比目录版慢（实测首次几秒），介意就用 `portable.zip`。
- 免安装版没有自动更新，升级要手动换程序（见「九、更新」）。
- 开机自启记录的是程序的真实路径（单文件版会自动用启动器路径，而不是临时目录）；开发模式下不会写系统启动项。
